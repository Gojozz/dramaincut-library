Tambah Pustaka DramainCut

Halaman ini mengunggah file ke repo Gojozz/dramaincut-library dan menambahkan entrinya ke catalog.json, sehingga item langsung muncul di aplikasi tanpa update APK. Token hanya tersimpan di perangkat ini dan hanya dikirim ke api.github.com.

Cara membuat token
  1. Buka github.com/settings/tokens?type=beta → Generate new token.
  2. Repository access: Only select repositories → pilih dramaincut-library saja.
  3. Permissions → Repository permissions → Contents: Read and write. Yang lain biarkan kosong.
  4. Generate, salin tokennya, tempel di kolom atas, lalu tekan Simpan Token.
